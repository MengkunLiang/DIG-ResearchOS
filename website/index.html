Four core capabilities

Four transitions that keep the research connected.

Each stage produces a durable output that becomes the next stage’s input.

01 · Research Evidence

Turn literature into a research space.

Verified papers become structured evidence records. Cross-paper synthesis connects mechanisms, findings, tensions, and open opportunities.

  • Typed paper cards with provenance and reading coverage
  • Mechanism, design rationale, and claim support
  • Cross-paper synthesis across evidence and tensions
OutputResearch space
02 · Idea Evolution

Evolve a portfolio before selecting a direction.

Multiple research routes are generated, scored independently, and refined through bounded mutation and crossover before researcher selection.

  • Multi-route candidate generation
  • Independent scoring and parent–child comparison
  • Mutation, crossover, survival, and portfolio selection
OutputSelected research direction
03 · Execution Compilation

Compile a research plan into executable work.

The accepted blueprint becomes project-specific Skills, execution constraints, and a structured handoff for Codex, Claude Code, or a human executor.

  • Research blueprint and experiment contract
  • Project-specific Skills and resource boundaries
  • Structured result package for the writing stage
OutputValidated execution handoff
04 · Evidence-to-Manuscript

Build the manuscript from accepted evidence.

Literature, experiment facts, figures, and tables are indexed and routed to the sections that need them, then checked again at claim level.

  • Evidence and resource indexing before drafting
  • Section-level evidence routing
  • Review, revision, claim audit, and submission bundle
OutputClaim-audited manuscript

Quick start

Start with a workspace.

Connect your model, create a project workspace, and launch the governed research pipeline.

Quick Start ↗ Pipeline ↗ External Executor ↗ 中文文档 ↗
Terminal
# Configure the model connection
python -m researchos.cli configure-llm

# Create a project workspace
python -m researchos.cli init-workspace \
  --workspace ./workspace/project-a \
  --project-id project-a \
  --topic "your research topic"

# Run the pipeline
python -m researchos.cli run \
  --workspace ./workspace/project-a
