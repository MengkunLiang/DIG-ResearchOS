Four core capabilities

Four capabilities. One connected research record.

Build a research space, evolve ideas, compile experiments, and write with evidence—all within one connected workspace.

01 · Research Evidence

Turn literature into a research space.

Verified papers become structured evidence records. Cross-paper synthesis connects mechanisms, findings, tensions, and opportunities.

Paper identity & reading coverage Mechanism and design rationale Claims linked to evidence Cross-paper synthesis
02 · Idea Evolution

Evolve ideas into a research direction.

Generate and compare multiple research routes. Independent scoring, mutation, and crossover refine a portfolio for researcher selection.

Multi-route generation Independent scoring Mutation & crossover Portfolio selection
03 · Execution Compilation

Turn a research plan into executable work.

The accepted blueprint becomes project-specific Skills, protocols, and a structured handoff for Codex, Claude Code, or a human executor.

Research blueprint Project-specific Skills Protocol & resource contract Writer Handoff
04 · Evidence-to-Manuscript

Build every section on evidence.

Index literature, experimental facts, figures, and tables. Route evidence into the manuscript, then review, revise, and audit its claims.

Evidence & resource indexes Section-level routing Review & revision Claim audit & submission bundle

Quick start

Start with a workspace.

Connect your model, create a project workspace, and launch the research workflow.

Quick Start ↗Pipeline ↗External Executor ↗中文文档 ↗
Terminal
# Configure the model connection
python -m researchos.cli configure-llm

# Create a project workspace
python -m researchos.cli init-workspace \
  --workspace ./workspace/project-a \
  --project-id project-a \
  --topic "your research topic"

# Run the pipeline
python -m researchos.cli run \
  --workspace ./workspace/project-a
