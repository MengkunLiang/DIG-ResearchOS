A durable research runtime

A research project outlives any model call.

Long-running work needs persistent state, evidence boundaries, explicit decision authority, and safe recovery. ResearchOS makes those requirements part of the runtime so every major research transition leaves an inspectable record.

Quick start

Start with a workspace.

Configure the model connection, create one project workspace, then run the governed pipeline.

Quick Start ↗Pipeline ↗External Executor ↗中文文档 ↗
Terminal
# Configure the model connection
python -m researchos.cli configure-llm

# Create a project workspace
python -m researchos.cli init-workspace \
  --workspace ./workspace/project-a \
  --project-id project-a \
  --topic "your research topic"

# Run the pipeline
python -m researchos.cli run \
  --workspace ./workspace/project-a
