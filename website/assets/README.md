# ResearchOS demo media

The project page uses the real ResearchOS workflow demo directly after the hero.

```text
website/assets/
├── researchos-main-flow.webm
```

Recommended encoding:

- 720p–1080p screen recording
- WebM for compact delivery
- H.264 MP4 for broad browser compatibility
- WebP poster from a representative system state
